# Leonida Legend — GTA VI Trophy Guide & Tracker

An offline web app that guides and tracks all 55 Grand Theft Auto VI PlayStation 5 trophies: every trophy with its official name, description and grade, a guide to each in our own words that cites its source (the official description it is derived from), a six-stage roadmap to the platinum built from those descriptions, 17 missable trophies flagged with their points of no return, kind / grade / state filters and search, a spoiler shield that hides the 28 hidden trophies until they are earned, and progress saved in the browser (localStorage) with export to and import from a JSON file. Dark Vice-inspired look, original art only — no Rockstar logos or artwork — and no network requests at run time.
